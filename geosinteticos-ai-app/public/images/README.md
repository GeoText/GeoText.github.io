# Imagens

Coloque aqui fotos e ilustrações dos materiais.

Exemplos de nomes:
- `geotextil-nao-tecido-01.jpg`
- `geotextil-tecido-01.jpg`
- `geogrelha-biaxial-01.jpg`
- `geomembrana-pead-01.jpg`

Depois altere o campo `imagem` em `data/geosinteticos.json`.

Evite usar imagens de fabricantes sem verificar a licença/permissão de uso.
