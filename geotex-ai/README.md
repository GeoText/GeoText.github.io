# GeoTex AI

Plataforma inteligente para identificação, seleção e dimensionamento de geossintéticos em obras de engenharia.

## Objetivo

Ajudar engenheiros, estudantes e profissionais da construção a:
- **Identificar** geossintéticos por foto, nome ou descrição.
- **Entender** as funções e aplicações de cada material.
- **Selecionar** a melhor solução para uma determinada obra.
- **Verificar** tecnicamente se um produto atende aos critérios de projeto.
- **Encontrar** fornecedores e fabricantes próximos.

## Estrutura do Repositório

- `apps/` – Aplicações (site e app mobile)
- `packages/` – Módulos compartilhados (catálogo e cálculos)
- `docs/` – Documentação técnica e catálogos

## Como Começar

```bash
# Instalar dependências
npm install

# Rodar o site (desenvolvimento)
npm run dev:web

# Rodar o app (expo)
npm run dev:mobile
```
